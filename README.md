# سهم Chess — v0.5 (بنية متعددة الشاشات)

مشروع Android أصلي بلغة Java، بدون مكتبات خارجية، يعمل بالكامل Offline.

---

## 1) ملخص ما تم تطويره

انتقل المشروع من "شاشة واحدة فيها كل شي" إلى **تطبيق متعدد الشاشات فعليًا** (Home → Play / Settings، مو كل شي بشاشة وحدة)، مع محرك أقوى، رقعة قابلة للتخصيص الكامل، نظام لعب متكامل (لا شكلي)، وتحليل نقلات حقيقي عند الطلب.

## 2) الملفات

| الملف | الحالة | الوصف |
|---|---|---|
| `Chess.java` | معدَّل (إضافة صغيرة فقط، لم يُعَد كتابته) | إضافة `best(board, timeMs, maxDepth)` لدعم مستويات الصعوبة، بدون لمس بقية المحرك (كان سليمًا من مرحلة سابقة). |
| `HomeActivity.java` | **جديد** | الشاشة الرئيسية: بطاقات لكل قسم (لعب AI / محلي / ضد نفسك / إعدادات) + أقسام قادمة موضّحة بصراحة. |
| `PlayActivity.java` | **جديد** (يحل محل `MainActivity.java` المحذوف) | شاشة اللعب الكاملة: إعداد المباراة، الرقعة، التحكم، التحليل. |
| `SettingsActivity.java` | **جديد** | كل إعدادات الرقعة/الصوت/اللعب/المظهر، محفوظة دائمًا. |
| `Prefs.java` | **جديد** | مخزن الإعدادات (SharedPreferences) + تعريف ثيمات الألوان وأنماط القطع. |
| `SoundFx.java` | **جديد** | أصوات نقلة/أخذ/كش/نهاية اللعبة عبر `ToneGenerator` (بدون ملفات صوت خارجية). |
| `ComingSoonActivity.java` | **جديد** | شاشة صريحة لأي قسم غير مبني بعد — تشرح الميزة المخطَّطة وسبب تأجيلها، **بدون** أي زر وهمي. |
| `MainActivity.java` | **محذوف** | استُبدل بالكامل بـ`HomeActivity` + `PlayActivity`. |
| `AndroidManifest.xml` | معدَّل | `HomeActivity` هي نقطة الانطلاق الآن + تسجيل الشاشات الجديدة. |

## 3) الميزات التي تعمل فعليًا الآن

**التنقل:** الرئيسية → لعب (AI / محلي لاعبان / ضد نفسك) → الإعدادات — شاشات منفصلة حقيقية.

**الرقعة الاحترافية:** 5 ثيمات ألوان، نمطين للقطع، 3 أحجام، إظهار/إخفاء الإحداثيات، قلب الرقعة، تمييز آخر نقلة، تمييز المربعات القانونية عند اختيار قطعة، تمييز الملك بالأحمر عند الكش، تشغيل/إيقاف الأصوات — كلها محفوظة بالإعدادات وتُقرأ حيًّا بكل رسم.

**نظام اللعب:** اختيار اللون (أبيض/أسود/عشوائي) والصعوبة (4 مستويات فعلية — مش أسماء فقط: تختلف بعمق البحث ووقت التفكير، والمبتدئ يلعب أحيانًا نقلة عشوائية عمدًا ليكون ضعيفًا فعلًا)، وقت مباراة اختياري (بدون/5/10/15 دقيقة) بساعة حقيقية تعد تنازليًا وتُنهي المباراة عند انتهاء الوقت، Undo فعلي (يتراجع بنقلتين بوضع AI ليرجعلك دورك)، استسلام، عرض تعادل (بوضع AI المحرك فعليًا يقيّم الوضعية ويقبل/يرفض بدل قبول تلقائي وهمي)، ترقية بيدق باختيار حقيقي (وزير/رخ/فيل/حصان) إذا عطّلت "الترقية التلقائية"، تأكيد النقلة قبل تنفيذها (اختياري).

**سجل النقلات:** نص SAN صحيح (بما فيه x للأخذ و+ / # للكش وكش الملك)، قابل للضغط، تنقل كامل (⏮ ⏪ مباشر ⏩ ⏭) لمراجعة أي وضعية سابقة، مع منع اللعب أثناء المراجعة (لتفادي كسر السجل) وزر رجوع فوري للمباراة الحالية. نسخ PGN صحيح (Headers + نتيجة) للحافظة.

**تحليل النقلات (عند الطلب):** زر "🔍 تحليل" على أي نقلة بالسجل يشغّل المحرك فعليًا على الوضعية قبلها، يقارن نقلتك بأفضل نقلة، ويعطي تقييمًا رقميًا (+0.8 مثلًا) وتصنيفًا: أفضل نقلة / ممتاز / جيد / غير دقيق / خطأ / خطأ فادح. زر "💡 تلميح" يقترح أفضل نقلة بأي وضعية بدون إلزامك تلعبها.

**لعب ضد نفسك ولعب محلي:** نفس شاشة اللعب، فقط بدون خصم AI — تحرّك الطرفين بنفسك.

## 4) ما لم يُنفَّذ كليًا، ولماذا (بصراحة تامة)

هاي مو أزرار وهمية — هاي أقسام حطيتلها شاشة "قيد التطوير" واضحة تشرح ليش، حسب طلبك بالضبط:

- **التدريب (تكتيكات/نهايات/كش مات) والـ Puzzles:** تحتاج بنك تمارين محقّق (مئات المواقع الصحيحة مع الحل)، ما بينبنى بنزاهة بردة وحدة بدون تدقيق كل موقعة.
- **المباريات الشهيرة:** تحتاج PGN حقيقي وموثّق لكل مباراة (طلبت بنفسك بالحرف: "لا تخترع مباريات أو نتائج") — يحتاج جمع وتدقيق مصادر، مو توليد.
- **شجرة الافتتاحيات الكاملة + الاختبار التفاعلي:** المحرك فيه كتاب افتتاحيات أساسي (12 خط) يشتغل فعليًا بمباريات AI، لكن الشاشة التفاعلية الكاملة (اختيار افتتاحية → تمرين → اختبار) لسا ما بُنيت.
- **دروس "تعلم الشطرنج" من الصفر:** محتوى تعليمي طويل يحتاج كتابة دقيقة تدريجية.
- **الإحصائيات وProfile:** تحتاج تخزين تاريخ مباريات متعدد (مش لعبة وحدة بالذاكرة زي هلق) — بنية قابلة للإضافة لاحقًا.
- **AI Coach بمحادثة حرة:** بدون مفتاح API خارجي (زي ما طلبت بالضبط: "لا تدّعِ AI Chat حقيقي بدون API")، المدرب الحالي يعتمد فعليًا على تحليل المحرك (تلميح/تحليل نقلة) لا على محادثة حرة.
- **استيراد PGN:** مؤجَّل عمدًا — يحتاج Parser لمطابقة SAN بدقة، وتنفيذه بدون اختبار فعلي على أجهزة حقيقية (بيئتي هلق بدون Android SDK) خطر أعلى من قيمته الآن. التصدير/النسخ شغّال بالكامل.

## 5) طريقة التشغيل والاختبار

نفس طريقة البناء بـGitHub Actions من الإصدار السابق (`.github/workflows/build-apk.yml` موجود وسليم). بعد التثبيت:
1. افتح التطبيق → الشاشة الرئيسية.
2. جرّب "لعب ضد الذكاء الاصطناعي" → اختر لون/صعوبة/وقت → العب نقلة → راقب رد الخصم.
3. من السجل، اضغط أي نقلة سابقة، جرّب "🔍 تحليل" و"💡 تلميح".
4. من الرئيسية → "⚙️ الإعدادات" → بدّل ثيم الرقعة/شكل القطع/الحجم وارجع للعبة للتأكد إنها تطبّقت.
5. جرّب الأقسام "قيد التطوير" للتأكد إنها توضّح الحالة بدل ما تتوقّع شي وتلاقي زر فاضي.

> ملاحظة صريحة: هاي الشيفرة كتبتها ودققتها يدويًا سطرًا سطرًا (توازن الأقواس، تطابق توقيعات الدوال بين الملفات)، لكن بيئتي الحالية بدون Android SDK/مترجم فعلي، فما قدرت أشغّل Build حقيقي هون قبل ما أسلّمك الملف. أول بناء فعلي رح يصير على GitHub Actions عندك — إذا طلع أي خطأ ترجمة، الصقيه إلي وبصلّحه فورًا بأقل تعديل ممكن.

## 6) خارطة طريق مقترحة (المرحلة القادمة)

1. Puzzle Mode ببنك تمارين صغير محقَّق يدويًا (10-20 مسألة للبداية) بدل الادّعاء بمئات.
2. شاشة Opening Trainer تفاعلية فوق كتاب الافتتاحيات الموجود بالمحرك.
3. تحليل تلقائي (Game Review) لكامل المباراة بعد الانتهاء بدل نقلة نقلة يدويًا.
4. استيراد PGN.
5. Profile/Statistics بتخزين تاريخ عدة مباريات.
6. مباريات شهيرة موثّقة (تبدأ بـ 5-10 مباريات مدقّقة المصدر).

## البناء التلقائي (GitHub Actions) — بدون أي برنامج
1. أنشئ مستودع GitHub فاضي، ارفع كل محتويات `SahmChess_Pro` (بما فيها `.github`).
2. تبويب Actions → انتظر يخلص (✔) → افتحه → حمّل `SahmChess-debug-apk` من Artifacts.
3. فك الضغط، انسخ APK لتلفونك، فعّل "تثبيت من مصادر غير معروفة"، ثبّته.

## البناء اليدوي (Android Studio)
افتح `SahmChess_Pro` بـAndroid Studio (SDK 35) → Gradle Sync → `Build > Build APK(s)`.
